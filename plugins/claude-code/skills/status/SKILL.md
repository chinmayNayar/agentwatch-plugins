---
name: status
description: Show whether AgentWatch is watching this session: mode, sign-in, passport, queued events.
---

Call the `agentwatch_status` tool from the `agentwatch` MCP server and show the result to the user.
Keep it short: lead with the answer, then the details that matter. If the tool says the
machine is not signed in, tell the user to run `agentwatch login` in a terminal.

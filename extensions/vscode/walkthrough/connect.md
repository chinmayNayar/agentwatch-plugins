# Connect your coding agents

The Connect panel finds Claude Code, Cursor, Codex and GitHub Copilot on this machine and shows the exact change to each hook file before anything is written.

- Hooks go into your **user** settings, never into files you commit.
- The original file is backed up; **Uninstall** restores it byte-for-byte when you have not changed it since.
- `agentwatch doctor` shows green or red per agent.
